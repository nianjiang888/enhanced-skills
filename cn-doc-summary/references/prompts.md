# 中文长文摘要：场景维度、结构模板与去 AI 味清单

本文件是 `cn-doc-summary` 的配套依据库，把正文里提到的提取维度、摘要结构和自检清单固化下来，方便照着执行。

## 一、五类文本的提取维度

| 文本类型 | 重点提取 | 可引用标记 |
|---|---|---|
| 观点文（公众号深度、知乎长答） | 核心论点、论证链条、反方观点、作者立场 | 原话金句、数据 |
| 报告/研报（PDF、飞书） | 结论、关键数据、方法论局限、行动建议 | 数据表、结论句 |
| 教程/实操文 | 步骤、前置条件、坑点、可复用模板 | 命令/代码片段、配置项 |
| 会议记录/访谈 | 决策、行动项、责任人、待决问题 | 决议原话、deadline |
| 新闻/资讯 | 事件、当事方、时间线、影响面 | 时间、主体、数字 |

## 二、摘要结构模板（结论先行）

```
【一句话结论】
（这篇文到底在说什么，或对你意味着什么）

【背景】为什么写
（针对什么现象/问题，一两句）

【核心论点】
1. ……（配一句支撑）
2. ……
3. ……

【关键证据】
（最硬的一两个，附可引用原话与出处节次）

【反方/局限】
（作者没说清的、有争议的，标出来）

【行动项】
（读者能马上做什么）
```

老板版只要"一句话结论 + 核心论点 + 行动项"三块，压到 200 字内。

## 三、去 AI 味自检清单

- [ ] 无破折号引导的副标题式句子（"—— 这才是关键"）
- [ ] 无空话词堆砌（"值得注意的是""总体而言""不难看出""某种程度上"）
- [ ] 无假精确数字（原文没给的不写，写"未给出具体数据"）
- [ ] 中英文标点不混用（中文句用全角逗号、句号、括号）
- [ ] 无工整排比三连（打乱节奏，长短句参差）
- [ ] 无 emoji 当格式符号
- [ ] 无"首先/其次/最后"的机械分段（用自然过渡）

## 四、引用规范

- 可引用原话用中文双引号标出
- 注明来源位置：第几节或大致段落，如"（见第三节）"
- 数据是原文的就标"原文数据"，是自己推算的标"据原文估算"
-  paraphrase 不等于引用，转述时不加引号；只有原话才加引号

## 五、受众适配速查

| 受众 | 结构侧重 | 长度 |
|---|---|---|
| 老板/决策层 | 结论 + 依据 + 行动项 | ≤200 字 |
| 同事/协作方 | 要点 + 可操作 + 坑点 | 原文 1/10 |
| 自己知识库 | 论点 + 出处 + 可检索标签 | 原文 1/5 |
| 客户/外部 | 利益 + 价值 + 案例 | 原文 1/8 |
