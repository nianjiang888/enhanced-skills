# 翻译校对检查清单与场景标准

本文件是「中文翻译校对与本地化质检」的配套依据库：翻译腔清单、四场景标准、术语表模板、输出模板。

## 一、翻译腔识别清单（逐句过）

| 问题 | 典型表现 | 改法 |
|---|---|---|
| 被字句滥用 | "被广泛应用于" | "广泛应用于" |
| 代词堆砌 | "该用户""其与" | "这个用户""它和"（正式文档可保留） |
| 长定语嵌套 | "为了实现……的……功能" | 拆成短句 |
| 英式语序 | "具有重要的意义" | "很重要" |
| 副词垫话 | "事实上""值得注意的是" | 能删就删 |
| 工整三连 | "不仅……更……还……" | 打乱节奏 |
| 中英混排标点 | 中文句夹英文逗号/括号 | 统一全角 |
| 名词化堆叠 | "进行……的操作" | 直接用动词 |

## 二、四场景标准

| 场景 | 首要标准 | 容忍度 |
|---|---|---|
| 技术文档 | 准确、术语统一、零歧义 | 错一个术语=事故 |
| 产品文案 | 简洁、语气一致、品牌感 | 拗口只是减分 |
| 营销文案 | 感染力、文化适配、冲劲 | 可适度意译 |
| 用户通知 | 清晰、零歧义、可执行 | 歧义=事故 |

## 三、术语表模板

```
| 原文 | 固定译法 | 备注 |
|---|---|---|
| SkillHub | SkillHub（不译） | 品牌名 |
| 墨金格 | 墨金格 | 产品名 |
| prompt | 提示词 | 行业通用 |
```

术语表以用户给的为准；没给按行业通用译法并标注"建议"。

## 四、句级置信分

- 准确：译文完整传达原意，无漏无增
- 疑误：可能漏译/增译/误译，已标具体位置
- 错译：意思偏离，必须改

## 六、硬检查纪律

- 占位符/变量（{name}/%s/{{var}}）原样保留
- 代码块、命令、路径、URL 不译
- 数值/单位/日期格式按目标语言规范
- 标签/菜单/按钮文案与产品实际一致
