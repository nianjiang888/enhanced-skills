# 中文增强版技能集（Enhanced CN）

3 个自包含 Agent 技能：中文长文摘要、中文代码审查、中文会议纪要，针对中文场景与团队习惯做本地化增强。

共 **3** 个技能包，全部自包含（包内即可跑通，无需额外依赖）。

## 技能一览

| # | 技能包 | 名称 | 做什么 |
|---|---|---|---|
| 1 | `cn-code-review` | 中文代码审查 | 对代码改动做中文代码审查，按上下文、高层、逐行、总结四阶段推进，用严重度标记区分阻塞项与建议项，并对每条反馈独立评估… |
| 2 | `cn-doc-summary` | 中文长文与报告摘要 | 把公众号、知乎、飞书、研报等中文长文或报告，按受众与目的做成结论先行、可引用、去 AI 味的结构化摘要。 |
| 3 | `cn-meeting-notes` | 中文会议纪要整理 | 把会议录音转写稿或零散笔记，整理成结论先行、行动项带责任人和截止时间的中文结构化纪要，并清理口语赘词。 |

## 目录结构

```
enhanced/
├── cn-code-review/
├── cn-doc-summary/
├── cn-meeting-notes/
├── ...（共 3 个技能目录）
```

每个技能包结构：`SKILL.md`（技能定义）+ `references/`（配套依据库：检查项、清单、模板）。纯指令型技能，无脚本依赖，Agent 读取 SKILL.md 即按工作流执行。

## 本地使用

```
git clone <仓库地址>
```

把需要的技能目录整体复制到你的 Agent skills 目录即可。技能由 Agent 读取 `SKILL.md` 后按工作流执行，无需单独运行脚本。

## 从 GitHub 导入到 SkillHub

每个技能独立目录，目录根即 `SKILL.md`，不含二进制文件。在 SkillHub 发布页选「从 GitHub 导入」，绑定账号后会自动扫出候选技能。

**注意：平台单次最多导入 5 个技能，5 个正好 1 批导入。**
