# 选题来源操作手册与判定基准

这份文件是 `cn-content-topic` 的实操依据。技能主文件讲的是流程，这里给能直接照着做的步骤、模板和清单。

## 一、六路选题来源的实操步骤

### 第一路：定位反推

把目标人群写成一句具体到能画像的话，然后列他们的问题清单。

```
模板：我要写给【具体人群画像】，他们现在最头疼的是【具体场景下的具体问题】。
```

画像越粗，选题越泛。判断标准：这句话能不能让一个真人觉得"说的就是我"。

列问题时按三个阶段铺：

- 事前：他在纠结什么、怕踩什么坑、要不要做
- 事中：他卡在哪一步、最费时间的是什么、有没有更省事的做法
- 事后：怎么判断做得对不对、怎么复盘、下一步怎么走

### 第二路：自有数据归因

把历史内容按表现分成两堆，各找共同点。别只看播放量，要看这三个：

| 指标 | 看什么 |
|---|---|
| 打开率或点击率 | 标题和封面的问题，跟选题类型相关性最高 |
| 完播率或读完率 | 钩子和内容结构的问题 |
| 互动率 | 选题有没有戳到表达欲，有没有留话口 |

归因时只问一句：**这条好或差，是选题的问题，还是执行的问题？** 选题层面的结论（比如"具体数字加实操类在我这跑得动"）才值得沉淀成规则，执行层面的（比如"那次封面太乱"）只影响单条。

### 第三路：对标账号

找三到五个同赛道做得好的账号，各扒近三个月互动最高的十条，填这张表：

| 账号 | 高互动选题 | 选题类型 | 标题句式 | 我能做类似的角度吗 |

重点不是抄选题，是找**反复被验证的选题类型**。同一个类型出现三次以上，说明这个人群确实吃这一套。

### 第四路：平台热榜与搜索

- 热榜：看平台当下在推什么
- 搜索下拉和相关搜索：看真实用户在搜什么词，这是最诚实的需求信号
- 话题页和合集：看某个话题下已经有哪些内容、还缺什么角度

采集时记时间，热榜类选题有保质期，超过一周的价值衰减很快。

### 第五路：评论区与私信

这是含金量最高也最容易被忽略的一路。做法：

- 去对标账号和自己账号的高互动内容底下，把提问类评论抄下来
- 分类：问"怎么做"的、问"值不值"的、问"我这种情况怎么办"的
- 第三类最好用，直接就是一条精准选题

### 第六路：节点日历

提前排一张表，按季度更新：

| 时间节点 | 相关人群会关心什么 | 提前多久准备 |

## 二、评分卡细化

四项各一到五分，打分标准：

| 项 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| 需求强度 | 只有我自己觉得重要 | 有零星讨论 | 明确有人搜、有人问 |
| 差异化 | 到处都是同款内容 | 有人讲但角度不同 | 我有别人拿不出的一手材料 |
| 可产出性 | 缺素材、写不动 | 需要补一点料 | 手上有料，能直接写 |
| 合规安全 | 明显踩线 | 要小心措辞 | 完全没问题 |

**合规安全得 1 分直接淘汰**，不做权衡。

总分十六分以上进第一梯队，十二到十五第二梯队，十二以下先放着。

## 三、标题策略库（可直接套的句式）

### 具体数字加实操

```
【数字】个【具体对象】，【动作】的【结果】
花了【数字】【单位】才搞明白的【件事】
【数字】步搞定【具体事】，第【数字】步最容易错
```

### 痛点共鸣

```
【人群】最怕的不是【表面问题】，是【真问题】
做了【时间】才承认：【反直觉的事实】
【场景】里没人告诉你的【件事】
```

### 反常识

```
【普遍做法】其实是在【负面后果】
越【常见动作】越【反向结果】，【人群】尤其要注意
```

### 身份认同

```
做了【时间】【人群】的人，都懂这【数字】件事
【人群】才有的【具体困境】，外行根本理解不了
```

### 悬念缺口（慎用）

```
【结果】的原因，跟你想的不一样
我劝你别急着【动作】，先看完这个
```

**起标题的三条硬规矩**：

1. 每条标题只主打一个信息点，不要塞三件事
2. 具体优于抽象，能写"三家店"就不写"很多商家"
3. 不承诺结果，只承诺信息和视角

## 四、平台红线细化

### 通用（广告法层面）

禁用绝对化用语：国家级、最高级、最佳、第一、顶级、极致、唯一、首选、史无前例这类。不是说绝对不能用，是说用在自己或自己商品上就违规。

### 头条与西瓜

- 标题党：标题和正文严重不符
- 夸张承诺：包过、保过、稳赚、必看
- 收益诱导：靠这个月入多少、轻松变现
- 涉政、社会敏感话题的蹭热点

### 小红书

- 绝对化用语与功效承诺，医美、保健、减肥类尤其严
- 导流外链与站外联系方式
- 搬运他人内容、非原创声明
- 伪测评、软广不标

### 抖音与视频号

- 极限词
- 诱导互动：点赞发财、不转不是、转发保平安
- 未经证实的健康建议、财经预测、投资建议
- 画面与字幕的低俗、惊悚元素

### 公众号

- 诱导分享与关注
- 标题夸大
- 未授权转载与洗稿

## 五、去 AI 味检查清单

出稿前逐条过：

- [ ] 标题里没有"探索、赋能、深度解析、一文读懂、全攻略"这类词
- [ ] 没有三段式排比句堆叠
- [ ] 没有口号式金句收尾
- [ ] 有具体的人、事、数字，不是通篇抽象概括
- [ ] 句子长短参差，不是每句都一个长度
- [ ] 允许口语化表达和括号补充
- [ ] 有明确的个人立场，不是两头都不得罪
- [ ] 没有 emoji 充当结构符号

## 六、排期与复盘

### 排期原则

- 高确定性选题（验证过的类型）打底，占总量的六到七成
- 试探性选题（新角度、新形式）占三到四成，用来找下一个确定性
- 节点类选题提前一到两周准备，别临时赶

### 复盘节奏

每发满二十条复盘一次，只看三个问题：

1. 哪类选题类型跑得动，进确定性池
2. 哪类标题句式的打开率明显高，进标题策略库
3. 哪几条是执行问题不是选题问题，单独记下来下次规避

复盘结论写回这个技能的使用说明，形成自己的选题规则库。
