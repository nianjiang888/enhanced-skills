# 中文内容选题与标题工程

市面上已经有不少"给一个主题、出一篇成品"的写作技能（比如 Viral_Writer_Skill 这类，用十几个内容洞见维度做内部构思，再按平台规范出正文、出多个备选标题、给配图提示词）。它们解决的是"主题已定、怎么写出爆款"。

这个技能解决的是它上游那一步：**主题从哪来、几十个选题里先写哪个、标题怎么起才不扑街、哪些写法会踩平台红线**。

## 什么时候用

- 账号冷启动，不知道该写什么
- 要稳定更新但选题榨干了
- 内容数据忽高忽低，想从选题层面找原因
- 要批量铺一批内容（系列课、矩阵号、活动期），需要一次排出选题表
- 标题总起不好，打开率上不去

## 六路选题来源

选题不是等灵感，是可以被系统性挖出来的。六条路，每条都要真跑：

1. **定位反推**：从账号定位和目标人群倒推他们的问题清单。人群画像越具体越好——写"中小企业老板"不如写"刚开第二家店、开始管人的餐饮老板"
2. **自有数据**：翻自己的历史内容，把爆款和扑街分开归因。爆款的共同点是什么（话题类型、标题句式、开头钩子、发布时间），扑街的踩了什么坑
3. **对标账号**：找三到五个同赛道做得好的账号，扒他们近三个月的高互动内容，看哪些选题被反复验证
4. **平台热榜与搜索**：热榜、搜索下拉、相关搜索、话题页，看真实用户在搜什么
5. **评论区与私信**：含金量最高的一路。用户在别人内容底下问的问题，就是还没被满足的需求
6. **节点日历**：行业会议、政策发布、节假日、开学季、财报季、平台活动，提前排内容

## 评分卡：决定先写哪个

每个候选选题过这四项，各打一到五分：

- 需求强度：是真有人搜、有人问，还是你自己觉得重要
- 差异化：这个角度别人讲过没有，你能不能拿出别人没有的东西（一手经验、实测数据、真实案例）
- 可产出性：手上有没有素材，写不写得动，成本多高
- 合规安全：会不会踩平台红线，会不会涉及敏感表述

总分排序，前百分之二十到三十进选题池。**合规安全只能打一分的不管其他项多高，直接淘汰。**

## 标题工程

每条选题出三到五个候选标题，必须标注用的是哪种策略，方便事后复盘哪类句式有效：

| 策略 | 句式特征 | 适用 |
|---|---|---|
| 具体数字加实操 | 把数量、金额、时长、步骤写进标题 | 教程、测评、复盘类，实测高效的句式 |
| 痛点共鸣 | 直接说出目标人群正在经历的那个困扰 | 情绪类、行业吐槽 |
| 反常识 | 先抛一个跟直觉相反的结论 | 观点类，后面要有论据撑得住 |
| 身份认同 | 点名人群，比如"做了三年这个的人" | 圈层内容 |
| 悬念缺口 | 只给一半信息 | 慎用，容易做成标题党反噬完播和信任 |

**反面清单**（实测容易扑街或踩线）：

- 泛泛的"如何、怎么"开头，没有具体指向
- 承诺收益类，"轻松月入""包会""保证"——既容易违规也伤信任
- 求助接单类，"求推荐""有没有人需要"——那不是内容，是广告
- 极限词与绝对化用语——违反广告法，平台也限流

## 平台合规红线

不同平台尺度不一样，出稿前按目标平台过一遍：

| 平台 | 主要红线 |
|---|---|
| 头条与西瓜 | 标题党、夸张承诺、涉政敏感、收益诱导类表述 |
| 小红书 | 绝对化用语、医美与医疗功效承诺、导流外链、搬运 |
| 抖音与视频号 | 极限词、诱导互动、未经证实的健康与财经建议 |
| 公众号 | 诱导分享、夸大标题、未经授权的转载 |

共同遵守的硬约束：广告法禁用"国家级、最高级、最佳"这类绝对化用语；医疗、财经、教育、招商这些领域各有专项限制，涉及就查一遍平台最新公示规则。

## 输出结构

1. **选题池表格**：编号、选题、来源路径、四项评分、总分、优先级
2. **优先选题展开**：核心角度、三到五个候选标题（标策略）、首屏钩子（前三秒或前五十字）、需要准备的素材
3. **合规标注**：哪些选题或标题有风险，怎么改
4. **排期建议**：按节点日历和产出成本排更新顺序

## 去 AI 味要求

- 标题不用"探索、赋能、深度解析、一文读懂"这类腔调
- 不堆砌排比，不写口号式金句
- 用具体的人和事替代抽象概括——能写"我见过三家店都栽在这"，就不写"很多商家存在此类问题"
- 长短句参差，允许口语化，允许有个人立场

## 注意事项

- 选题和标题是概率工具，不承诺阅读量；效果要用自己的后台数据归因复盘
- 不编造数据、案例、用户原话；没有就标"需要补充素材"
- 平台规则会变，涉及具体限制时以平台最新公示规则为准
- 不代写涉及医疗诊断、投资建议、法律意见的结论性内容
- 方法论来源：公开内容运营方法（选题来源分类、选题评分、标题策略库、平台合规清单），非照搬任何特定仓库
