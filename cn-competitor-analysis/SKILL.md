# 中文竞品情报分析

你要在一个功能或产品方向真正动手之前，先搞清楚"外面已经有哪些人在做、他们强在哪弱在哪、你该卡什么位置"。海外同类技能（alirezarezvani/claude-skills 的 competitive-intel、wshobson 的 competitive-landscape、affaan-m 的 market-research）的核心是一套"5 层情报体系 + 2x2 威胁矩阵 + 战斗卡 + OSINT 维度跟踪"，而且强调"带出处、面向决策"。这套我们保留，但补上它们完全没有的中文信源和中文产品场景。

## 什么时候用

- 要做一个新功能/新产品，先验证"有没有人已经做了、做得怎么样"
- 老板或投资人问"我们这个方向和 XX 比怎么样"
- 销售要一份能直接用的战斗卡（battlecard）去打竞对
- 季度竞品复盘，跟踪对手最近的动作、定价、招聘信号
- 写融资 BP 或立项报告里的"竞争分析"章节

## 五步工作流

**第一步：锁定分析对象与问题**
先问清两件事，否则会写成"竞品罗列"：
- 分析对象是谁（你的产品/功能，还是某个赛道）
- 真正要回答的问题：是该不该做、该怎么定位、还是怎么打赢某个具体对手

不同问题，产出完全不同。面向"该不该做"给威胁矩阵和空白点；面向"怎么打"给战斗卡。

**第二步：竞品分层识别（5 层情报体系）**
不要只列"直接竞品"，分三层：

- 直接竞品：同一批客户、同一问题、相似方案、相近价位
- 间接竞品：抢同一笔预算、但解法不同（包括"客户啥也不做"和"自己造"）
- 潜在竞品：相邻赛道拿过钱的新团队、大厂路线图里明说要做的

配一张 2x2 威胁矩阵（同客户/不同客户 × 同问题/不同问题），每季度更新一次，看谁挪了象限。

**第三步：维度跟踪（中文信源）**
逐个竞品跟踪这些维度，每个维度记信源和采集时间：

| 维度 | 中文信源举例 | 节奏 |
|---|---|---|
| 产品动作 | 官网 changelog、应用商店更新、公众号 | 月度 |
| 定价变化 | 官网定价页、销售通话情报、客户反馈 | 触发式 |
| 融资动态 | 36氪、IT桔子、企名片、投资界 | 触发式 |
| 招聘信号 | BOSS直聘、拉勾、猎聘在招岗位 | 月度 |
| 工商股权 | 天眼查、企查查、国家企业信用信息公示系统 | 触发式 |
| 社媒声量 | 小红书、抖音、微博、视频号、B站 | 月度 |
| 搜索热度 | 微信指数、百度指数、巨量算数 | 季度 |
| 客户赢单/丢单 | 案例文章、应用商店评论、赢单复盘 | 持续 |

这套中文信源是海外版完全没有的——它们列的是 G2、LinkedIn、Crunchbase，国内基本用不了或数据薄。

**第四步：结构化合成（带出处、面向决策）**
固定产出四块：

1. **竞品档案**：每个对手的定价、产品成熟度、客户口碑、技术栈指纹、近期动作
2. **SWOT**（逐对手）：强项/弱项/可能威胁你的机会/它的生存风险
3. **2x2 定位图**：选两个对买家重要的轴（常见：价格 vs 功能深度；通用 vs 垂直），把对手摆上去，标出空白象限
4. **战斗卡（battlecard）**：针对某个具体对手，列出"客户为什么选我们不选手""对手常见异议怎么接""我们赢/输的规律"

所有结论必须挂信源（哪条信源、什么时间看到的），不编数据。原文没给具体数就写"未披露"。

**第五步：交付与更新建议**
给一份中文结构化简报即可。末尾给"下季度该跟踪什么变化"——哪几个维度一变就要重看结论。不要替老板下"该不该做"的判断，只把证据和空白点摆清楚。

## 与海外版的核心差异

- 信源是中文的：天眼查/36氪/微信指数/小红书/七麦 这套，海外竞品技能一个都没有
- 强调带出处：中文写作常要"拿公开信源当论据"，所以每条结论挂信源和时间
- 贴合中文产品场景：小程序/APP/SaaS/内容号，维度按这些定制
- 决策导向：西式报告常堆框架，这里要求"回答一个具体问题"

## 注意事项

- 只用公开信源，不碰付费数据库、不扒私密数据
- 不替被分析方下价值判断，弱项标"公开信息显示"，不代为背书
- 数据必须来自信源，没给就写"未披露"，不编"约 XX%"
- 这个技能不依赖外部工具，纯靠检索+重组；信源链接和采集时间要记下来备查
- 方法论来源：公开竞争情报框架（5 层情报体系 / 2x2 威胁矩阵 / 战斗卡 / SWOT / 波特五力），非照搬任何特定仓库
