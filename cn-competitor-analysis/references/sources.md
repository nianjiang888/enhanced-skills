# 中文竞品信源与框架模板

本文件是「中文竞品情报分析」的配套依据库：中文公开信源清单、四个核心框架的填写模板。海外竞品技能的信源（G2/LinkedIn/Crunchbase）在国内基本失效，下面这套才是能落地的。

## 一、中文公开信源清单（按维度）

| 维度 | 信源 | 能挖到什么 | 提示 |
|---|---|---|---|
| 工商股权 | 天眼查、企查查、国家企业信用信息公示系统 | 注册资本、股东、变更、分支机构、司法风险、招投标 | 免费版够用，看股权穿透 |
| 融资动态 | 36氪、IT桔子、企名片、投资界 | 轮次、估值、投资方、新闻 | 搜"公司名 + 融资" |
| 招聘信号 | BOSS直聘、拉勾、猎聘 | 在招岗位、技术栈、业务扩张方向 | 看"在招岗位"比 JD 更真 |
| 应用商店 | 七麦数据、点点数据、App Store 中国区、华为应用市场 | 下载量估算、版本迭代、评论 | 评论区是口碑金矿 |
| 社媒声量 | 小红书、抖音、微博、视频号、B站 | 内容量、互动、用户原声 | 搜品牌词/产品词 |
| 搜索热度 | 微信指数、百度指数、巨量算数 | 趋势、对比、人群画像 | 微信指数是公众号生态专属 |
| 官网/定价 | 官网、changelog、定价页 | 功能、迭代节奏、价格 | changelog 看产品重心 |
| 政采/招投标 | 中国政府采购网、各省市公共资源交易 | 大客户、政府关系 | 适合 ToG 方向 |

## 二、2x2 威胁矩阵模板

横轴：同客户 / 不同客户；纵轴：同问题 / 不同问题

```
            同问题                 不同问题
同客户   [直接威胁]              [替代风险]
不同客户 [相邻-观察]             [暂忽略]
```

每季度重画一次，标出"谁挪了象限"。

## 三、SWOT 模板（逐对手）

- 强项（Strengths）：它做得好的、赢面在哪
- 弱项（Weaknesses）：它丢单/被骂的点
- 机会（Opportunities）：它可能做、会威胁我们的
- 威胁（Threats）：它的生存风险（融资断、核心人走）

## 四、战斗卡（Battlecard）模板

针对一个具体对手：

- 一句话定位差："我们是 X，他们是 Y"
- 客户为什么选我们：3 条硬理由（带证据）
- 对手常见异议 + 接法：列 3-5 个"客户说 XX，我们回 XX"
- 我们赢的规律 / 输的规律：从赢单复盘里抽

## 五、TAM/SAM/SOM（立项用）

- TAM 总市场：赛道所有人
- SAM 可服务市场：你的形态能覆盖的
- SOM 可获取市场：当下资源能拿到的

## 六、采集纪律

- 每条结论挂信源链接 + 采集日期
- 没给具体数的写"未披露"，不估"约 XX%"
- 只用公开信源，不碰付费库、不扒私密数据
