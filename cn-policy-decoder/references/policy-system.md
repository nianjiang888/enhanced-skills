# 中国政策体系与申报拆解依据库

这份文件是 `cn-policy-decoder` 的判定基准。海外同类技能给的是英美法系那套，这里换成中国政策的实际规则。

## 一、效力层级（从高到低）

| 层级 | 制定主体 | 常见形式 | 辨识要点 |
|---|---|---|---|
| 法律 | 全国人大及其常委会 | 《XX法》 | 主席令公布，效力最高 |
| 行政法规 | 国务院 | 条例、规定、办法 | 国务院令公布 |
| 部门规章 | 部委 | 办法、规定、实施细则 | 部令公布（如应急管理部令第X号） |
| 规范性文件 | 各级机关 | 通知、意见、方案、函 | 带文号，俗称"红头文件"，数量最大、最常打交道 |
| 地方文件 | 省市县及园区 | 通知、方案、若干措施 | 文号带地区简称，仅在辖区有效 |

**冲突规则**：上位优于下位；新法优于旧法；特别优于一般；同一机关制定的，后文优于前文。

## 二、文号识别（拿到文件先看这个）

常见文号格式与含义：

| 文号样式 | 含义 |
|---|---|
| 国发〔2026〕X号 | 国务院发文，级别最高的一类政策 |
| 国办发〔2026〕X号 | 国务院办公厅发文 |
| 国办函〔2026〕X号 | 国务院办公厅函件，通常针对具体事项 |
| X部令 第X号 | 部委规章，效力高于普通规范性文件 |
| 工信厅科函〔2026〕X号 | 部委办公厅（厅）对具体事项的函，专项行动常见 |
| 桂政发〔2026〕X号 | 省级人民政府发文 |
| X市府办发〔2026〕X号 | 市级政府办公室发文 |

**三个判断要点**：

1. 有文号才是正式文件；没文号的"征求意见稿""草案"不能当申报依据
2. 转发件要顺藤摸瓜找原始发文，转发过程中常会加码或缩水
3. 文号年份不代表现行有效，可能被后续文件废止或替代

## 三、状态核验渠道

核验一份文件是否现行有效，走这些公开渠道：

- 国家法律法规数据库（全国人大）：法律法规与司法解释的权威版本
- 国务院政策文件库：国务院及办公厅文件的主动公开文本
- 各部门官网"政策文件"栏目：部委规章与规范性文件
- 各省市政府门户"政策库"与本地区"政策兑现平台"
- 国家企业信用信息公示系统、信用中国：涉企政策与失信名单

核验重点是三件事：有没有被废止、有没有修订版、配套细则出没出。

## 四、政策语言强度词表

中文公文的语气就是效力，这是解读的核心。

| 强度档 | 代表用词 | 意味着什么 |
|---|---|---|
| 强制 | 必须、应当、不得、严禁、一律、禁止 | 义务或红线，违反有后果 |
| 激励 | 支持、鼓励、引导、培育、扶持、优先 | 机会不是义务，通常需等配套细则 |
| 方向 | 推进、探索、研究、适时、逐步、鼓励探索 | 只表方向，不能当近期可兑现的承诺 |
| 量化 | 写死的比例、金额、数量、期限、家数 | 最硬的部分，可直接进测算模型 |

**两个高频误读**：

1. 把"支持、鼓励"当成"必须做"——白忙
2. 把"研究、探索"当成"马上能报"——踩空

反过来也要注意：有些文件正文用"支持"，但附件或实施细则里给的是硬指标和硬流程，那就要按细则走。

## 五、常见支持方式（申报视角）

| 支持方式 | 说明 | 常见门槛 |
|---|---|---|
| 资金补贴与奖补 | 一次性补助或按比例补助 | 投资额、营收、纳税、认定资质 |
| 各类券 | 算力券、语料券、创新券，按比例抵扣 | 平台注册、消费凭证、年度上限 |
| 资质认定 | 专精特新、高新技术企业、首台套 | 研发投入占比、知识产权、成长性指标 |
| 名录与资源池 | 进入服务商名录、供应商库 | 案例数量、团队规模、行业符合度 |
| 试点与示范 | 场景开放、试点城市、标杆项目 | 方案质量、联合体、地方配套 |
| 场景开放 | 政府或国企开放真实需求 | 需求匹配度、交付能力 |
| 税收优惠 | 加计扣除、税率优惠 | 会计核算规范、资质认定 |

## 六、申报材料常见清单

不同项目差异大，但高频项基本就这些：

1. 申报表（附件模板，按字段逐项填，别漏签字盖章）
2. 营业执照与资质证书复印件
3. 财务审计报告或纳税证明
4. 项目可行性报告或实施方案
5. 技术材料：知识产权、检测报告、查新报告
6. 业绩证明：合同、验收单、案例照片、用户证明
7. 人员材料：社保、职称、团队名单
8. 信用材料：无失信记录证明、信用中国截图
9. 联合申报的：联合体协议、各方分工

## 七、时间倒排模板

从申报截止日往前排，别从今天往后排：

| 距截止 | 动作 |
|---|---|
| 截止日 | 报送（留半天缓冲，系统卡是常态） |
| 前 1-2 天 | 全套材料盖章、扫描、上传、确认回执 |
| 前 3-5 天 | 内部复核：字段一致性、附件完整性、签字盖章 |
| 前 1-2 周 | 第三方材料到位：审计、检测、查新、信用证明 |
| 前 2-4 周 | 主体材料撰写：申报表、可行性报告、实施方案 |
| 前 1-2 月 | 缺口补齐：资质、案例、联合体、业绩材料 |

## 八、常见踩坑清单

- 拿征求意见稿当正式依据
- 只看正文不看附件（硬指标常在附件申报表里）
- 只看金额不看门槛（补贴高往往条件也硬）
- 忽略"补贴比例不超过 X%"和"年度上限"这类封顶条款
- 同一项目重复申报同类资金（多数政策明确禁止）
- 材料口径不一致：报告里的数字和财务报表对不上
- 错过形式审查：缺章、缺签字、附件格式不对，直接不进评审
- 政策说"另行发布实施细则"就以为能报了，实际细则可能根本没出

## 九、输出时的硬约束

- 金额、比例、数量以原文为准；原文没写就写"未明确"或"以实施细则为准"
- 状态不明必须写"需核验现行有效性"
- 不承诺"一定能拿到"
- 涉及法律、税务、资质定性的，提示以主管部门答复为准
